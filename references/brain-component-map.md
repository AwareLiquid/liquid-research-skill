# 人脑抽象模块 → 液态架构组件拆解

> 用途：把「研发类脑架构」这类泛目标，翻译成**可立项的具体组件任务**。每个组件都填实
> 7 个字段（功能目标 / 系统目标 / 输入 / 输出 / 交叉点 / 归纳偏置 / 验证方式），并映射到
> AwareLiquid 现有路线。评审或生成立项文档时直接套用。

## 从泛目标到组件（3 步）

**禁止泛目标**：❌「研发类脑架构」❌「优化模型效果」❌「提升智能水平」。
这些无法验收、无法拆边界，一律退回。

1. **把人脑拆成「功能系统」**（不是「智能」这种整体概念）。候选清单：
   神经元膜电位动力学、感觉编码、注意与门控、工作记忆、长时记忆、神经调质、
   突触可塑性、预测编码、审慎推理/路由。
2. **每个功能系统 → 一个可计算组件**，定义输入/输出边界。
3. **填实 7 字段模板**，其中「验证方式」必须能**独立验证该组件**（不依赖整体跑通）。
   7 字段全部填实才算立项就绪，缺一项退回补全。

## 逐组件规划

> 每个组件 = 一个独立立项任务。字段含义：功能目标（单点做什么）、系统目标（对整体的贡献）、
> 输入/输出（数据结构边界）、交叉点（与哪些组件交互及协议）、归纳偏置（引入了什么物理/认知先验）、
> 验证方式（如何**独立**验收）。

### 1. 液态核心状态模块（Liquid State Core）

- **对应人脑**：神经元膜电位动力学 + 突触电流（皮层微环路的连续膜动力学）
- **功能目标**：用 ODE `h'(t) = f(h, I, t, θ)` 连续演化隐状态，对时序输入做连续时间表征
- **系统目标**：为整个模型注入「连续时间动力学」原生归纳偏置，这是时序泛化/参数效率
  超越离散 Transformer 的根因
- **输入**：上游编码后的时序张量序列 `x_t`，或状态注入信号
- **输出**：连续演化状态 `h(t)`，可选的状态导数 `h'(t)`
- **交叉点**：接收「选择性门控」的更新/保留信号；向「混合注意力」「预测编码」「持久记忆」提供状态快照
- **归纳偏置**：连续时间动力学（LTC / 自适应时间常数）
- **验证方式**：固定下游不变，仅替换状态核，对比时序基准（sMNIST / 工业传感器 / 事件流）
  的泛化 gap 与「参数–性能」曲线
- **现有路线**：LTC substrate（AwareLiquid-Physic）、M1 核心

### 2. 感知编码模块（Sensory Encoding）

- **对应人脑**：丘脑中继 + 初级感觉皮层（V1/A1/S1）的稀疏编码
- **功能目标**：把异构原始信号（音频/传感器/事件流/物理量）投影到统一液态状态空间
- **系统目标**：多模态统一入口，避免每模态一套网络
- **输入**：原始模态信号（波形、事件流、传感器读数）
- **输出**：标准化时序嵌入序列
- **交叉点**：输出作为「液态核心状态」的输入注入
- **归纳偏置**：稀疏 / 脉冲编码、频率分解
- **验证方式**：同一状态核下，各模态的下游/重建误差对比；编码是否保留时序因果性
- **现有路线**：AwareLiquid-World 的 O-series 液态核心多模态编码、human-brain-simulation 的稀疏脉冲编码

### 3. 选择性门控模块（Selective Gating）

- **对应人脑**：丘脑的感觉门控 + 基底节的通路选择
- **功能目标**：决定「更新哪些状态 / 保留哪些 / 输出哪些」，实现稀疏激活
- **系统目标**：降低冗余计算，聚焦相关信号
- **输入**：状态 `h(t)` + 外部上下文
- **输出**：门控信号 `g ∈ [0,1]`，作用于状态更新与输出
- **交叉点**：直接调制「液态核心状态」的更新方程
- **归纳偏置**：稀疏选择、竞争机制
- **验证方式**：门控稀疏度 vs 性能权衡；消融门控后性能退化幅度
- **现有路线**：MT-LNN gating / capsule v2（M1）

### 4. 混合注意力层（Hybrid Attention）

- **对应人脑**：前额叶–顶叶注意网络（自上而下 / 自下而上注意）
- **功能目标**：在连续状态上做稀疏/选择性注意，替代全量 softmax 自注意力
- **系统目标**：长程依赖下的参数效率（O(1) 或近线性）
- **输入**：状态序列 + 查询信号
- **输出**：加权聚合的上下文表征
- **交叉点**：从「液态核心状态」取状态；结果回馈给状态或输出层
- **归纳偏置**：稀疏注意力、选择性
- **验证方式**：长序列依赖任务（LRA 类）的准确率–内存–延迟曲线 vs 全量注意力
- **现有路线**：sparse / selective attention（M1 探索）

### 5. 持久记忆模块（Persistent Memory）

- **对应人脑**：海马体（情景快速编码）+ 前额叶工作记忆（恒定保持）
- **功能目标**：O(1) 工作记忆（恒定缓存）+ 长期外部存储检索
- **系统目标**：恒定内存成本的上下文保持，支持超长上下文
- **输入**：需记住的 key–value 状态、查询
- **输出**：检索到的记忆，或更新后的记忆状态
- **交叉点**：从「液态核心状态」写入；被「审慎推理/路由」检索
- **归纳偏置**：恒定内存、读写分离
- **验证方式**：长上下文检索/召回基准（LongMemEval 类）上，内存增长 vs 召回率曲线应为 O(1)
- **现有路线**：O(1) working memory / cloud-augmented memory（M1）

### 6. 神经调质模块（Neuromodulation）

- **对应人脑**：多巴胺（奖赏/学习率）、血清素（耐心/时间尺度）、乙酰胆碱（注意/可塑性）
- **功能目标**：产生全局调制信号，调节学习率、探索–利用、时间尺度
- **系统目标**：让模型在训练/推理时动态调节行为，而非固定超参
- **输入**：全局奖励/误差/任务上下文
- **输出**：低维调制信号，广播到各模块
- **交叉点**：调制「可塑性学习规则」「选择性门控」的阈值与增益
- **归纳偏置**：全局低维调制、奖赏调制可塑性
- **验证方式**：改变调制信号能否切换行为模式（探索/利用）；奖赏调制是否提升稀疏奖励任务
- **现有路线**：待建（可借 human-brain-simulation 的调质建模）

### 7. 可塑性学习规则（Plasticity / Learning Rule）

- **对应人脑**：STDP / Hebbian / 奖赏调制突触可塑性
- **功能目标**：用局部学习规则替代/补充反向传播，降低显存与通信
- **系统目标**：在线、局部、低成本的参数更新
- **输入**：前后神经元活动（pre/post 时序）
- **输出**：权重更新 `Δw`
- **交叉点**：受「神经调质」调制；作用于「液态核心状态」权重
- **归纳偏置**：时序因果（STDP）、Hebbian
- **验证方式**：局部规则训练的收敛性与端到端 BP 的精度差；是否支持持续学习（不灾难性遗忘）
- **现有路线**：待建

### 8. 预测编码模块（Predictive Coding）

- **对应人脑**：皮层预测编码理论（预测单元 + 误差单元）
- **功能目标**：生成下一状态预测，用误差驱动修正（类扩散逐步去噪）
- **系统目标**：摆脱「下一个 Token 预测」单一拟合目标，引入「逐步修正」归纳偏置
- **输入**：当前状态 `h(t)` 或含噪状态
- **输出**：预测 + 误差信号
- **交叉点**：从「液态核心状态」取状态；误差反馈给状态演化（试点类扩散机制）
- **归纳偏置**：逐步去噪 / 逐步修正的物理过程假设
- **验证方式**：小规模验证范式收益——误差驱动的状态修正是否提升泛化（与纯自回归基线对比）
- **现有路线**：AwareLiquid-World 的 JEPA 式潜状态预测可作基础

### 9. 审慎推理 / 路由模块（Deliberation Router）

- **对应人脑**：前额叶 deliberate（System 2）系统 + 基底节动作选择
- **功能目标**：决定何时「快思考」直接输出、何时「慢思考」多步推理，并路由
- **系统目标**：计算资源的自适应分配
- **输入**：状态置信度、任务难度信号
- **输出**：路由决策（直出 / 展开推理 / 检索记忆）
- **交叉点**：调用「持久记忆」检索；控制「液态核心状态」的推理步数
- **归纳偏置**：自适应计算
- **验证方式**：简单任务不浪费计算、困难任务触发推理的准确率–计算量曲线
- **现有路线**：deliberation router（M1）

## 立项任务列表示例

把 9 个组件转成可执行任务清单（每个组件 = 一行任务，验收标准 = 该组件的「验证方式」）：

- **T1** 液态核心状态模块：落地 LTC 状态核，交付「参数–性能」曲线优于同参 Transformer 的时序基线
- **T2** 感知编码模块：统一音频/传感器/事件流三模态编码入口，交付多模态下游误差对比
- **T3** 选择性门控模块：MT-LNN gating / capsule v2 稀疏激活，交付消融退化幅度报告
- **T4** 混合注意力层：稀疏注意力替换全量 softmax，交付 LRA 类准确率–内存–延迟曲线
- **T5** 持久记忆模块：O(1) 工作记忆 + 外部存储，交付 LongMemEval 类召回率 O(1) 曲线
- **T6** 神经调质模块：低维调制信号调节探索/利用，交付行为切换 + 稀疏奖励提升验证
- **T7** 可塑性学习规则：STDP/Hebbian 局部规则，交付与 BP 的精度差 + 持续学习验证
- **T8** 预测编码模块：试点类扩散逐步修正，交付 vs 纯自回归基线的泛化对比
- **T9** 审慎推理/路由模块：deliberation router，交付准确率–计算量自适应曲线

**依赖关系**：T1 是地基（其余组件都挂在状态核上）；T2/T3/T4 依赖 T1 的状态表征；
T5/T9 依赖 T1 的状态快照；T6/T7 是横切模块，可并行、后期再接入。
**建议排期**：先 T1+T3+T5（核心闭环）→ T2+T4+T9（能力扩展）→ T6+T7+T8（范式探索，小步验证）。
