# 人脑抽象模块 → 液态架构组件拆解

> 用途：把「研发类脑架构」这类泛目标，翻译成**可立项的具体组件任务**。
> **本文件先分两层**——机制层（横切物理规律，不是「模块」）与功能系统层（真正的脑功能模块），
> 再用**环拓扑**描述连接（而非稀疏清单），避免把「电路基底」和「认知功能」混为一谈。

## 0. 为什么分两层

- ❌ 把「液态核心状态（连续时间动力学）」和「记忆」「注意」并列立项 → **类别错误**：
  连续时间动力学是物理基底，不是认知功能系统。
- ✅ 正确做法：机制层 = 贯穿所有模块的物理规律；功能系统层 = 脑的功能模块。
  机制承载功能，功能通过环路互连。

> 补充：除机制层 / 功能系统层 / 环拓扑外，还有第四维度「**数据形态 / 监督层**」——
> 数据形态直接决定拟合目标，换架构必须同步换数据。见 `data-form.md`。

## 1. 从泛目标到组件（3 步）

**禁止泛目标**：❌「研发类脑架构」❌「优化模型效果」❌「提升智能水平」。

1. 把「人脑」拆成**功能系统**（不是「智能」整体），候选清单见下方功能系统层表。
2. 每个功能系统 → 一个可计算组件，定义输入/输出边界；同时声明它挂在哪些**机制**上。
3. 填实 7 字段（功能目标/系统目标/输入/输出/交叉点环路/归纳偏置/验证方式），
   并把它定位进**环拓扑**。7 字段填实 + 环拓扑可定位 = 立项就绪。

## 3. 逐组件规划（功能系统层）

> 字段：对应人脑结构 / 功能目标 / 系统目标 / 输入 / 输出 / 交叉点（环）/ 归纳偏置 /
> 验证方式 / 现有路线。验证方式必须能**独立验收**（不依赖整体跑通）。

### 1. 感知编码模块（Sensory Encoding）

- **对应人脑**：丘脑感觉中继 + 初级感觉皮层（V1/A1/S1）+ 高阶感觉区
- **功能目标**：把异构原始信号（音频/传感器/事件流/物理量）投影到统一状态空间，稀疏/脉冲编码
- **系统目标**：多模态统一入口，保留时序因果性
- **输入**：原始模态信号
- **输出**：标准化时序嵌入序列
- **交叉点（环）**：丘脑–皮层双向环（与注意、工作记忆互连）；受预测编码误差驱动
- **归纳偏置**：稀疏 / 脉冲编码、频率分解
- **验证方式**：同一状态核下各模态下游/重建误差对比；编码是否保留时序因果
- **现有路线**：AwareLiquid-World / human-brain-simulation

### 2. 工作记忆模块（Working Memory）

- **对应人脑**：前额叶 PFC（恒定保持 + 门控刷新）
- **功能目标**：恒定缓存保持当前任务相关状态
- **系统目标**：恒定内存成本的上下文保持
- **输入**：需保持的状态 / 上下文
- **输出**：当前可用工作集
- **交叉点（环）**：CBGTC 环（基底节门控更新）；受注意调制；向海马写入情景
- **归纳偏置**：恒定内存、门控刷新
- **验证方式**：LongMemEval 类召回率–内存曲线应为 O(1)
- **现有路线**：O(1) working memory（M1）

### 3. 情景记忆模块（Episodic Memory）

- **对应人脑**：海马体（快速一次性编码 + 模式分离/完成）
- **功能目标**：对单次经历做快速编码与检索
- **系统目标**：支持 one-shot 记忆与情景回放
- **输入**：来自工作记忆 / 感知的事件流
- **输出**：检索到的情景 + 回放信号
- **交叉点（环）**：海马–皮层固化对话（向新皮层转移）
- **归纳偏置**：快速编码、模式分离 / 完成
- **验证方式**：one-shot 记忆检索基准；回放是否巩固长时记忆
- **现有路线**：待建（cloud-augmented memory 作长期存储底座）

### 4. 记忆固化模块（Memory Consolidation）

- **对应人脑**：新皮层 + 海马–皮层回放（睡眠 / 离线固化）
- **功能目标**：把海马情景逐步固化到长期权重，慢速、离线
- **系统目标**：从快速记忆到长期知识的转移
- **输入**：海马回放信号
- **输出**：固化后的长期表征
- **交叉点（环）**：海马–皮层固化对话
- **归纳偏置**：慢速固化、回放巩固
- **验证方式**：是否支持持续学习（不灾难性遗忘）；离线回放 vs 无回放对比
- **现有路线**：待建

### 5. 注意力模块（Attention）

- **对应人脑**：前额叶–顶叶注意网络 + 丘脑门控
- **功能目标**：对状态做稀疏/选择性注意，替代全量 softmax
- **系统目标**：长程依赖下的参数效率
- **输入**：状态序列 + 查询 / 目标信号
- **输出**：加权聚合的上下文表征
- **交叉点（环）**：丘脑–皮层环；调制工作记忆编码
- **归纳偏置**：稀疏 / 选择性注意
- **验证方式**：LRA 类准确率–内存–延迟曲线 vs 全量注意力
- **现有路线**：sparse / selective attention

### 6. 动作选择模块（Action Selection / RL）

- **对应人脑**：基底节 + 中脑多巴胺奖赏预测误差（RPE）
- **功能目标**：用 RPE 驱动选择（actor–critic）
- **系统目标**：强化学习信号驱动行为 / 生成策略
- **输入**：状态价值估计 + 奖赏信号
- **输出**：动作 / 选择 + RPE 信号
- **交叉点（环）**：CBGTC 环（皮层→纹状体→苍白球→丘脑→回皮层）
- **归纳偏置**：奖赏预测误差、actor–critic
- **验证方式**：稀疏奖励任务是否被 RPE 有效驱动；vs 纯监督基线
- **现有路线**：待建

### 7. 前向模型模块（Forward Model）

- **对应人脑**：小脑（内部前向模型 + 时序监督学习；约 80% 神经元）
- **功能目标**：预测下一步状态 / 时序，做误差驱动的时序修正
- **系统目标**：给系统一个「世界如何演化」的内部模型
- **输入**：当前状态 + 动作
- **输出**：下一状态预测 + 时序误差
- **交叉点（环）**：小脑–皮层环（皮层→脑桥→小脑→丘脑→回皮层）
- **归纳偏置**：前向模型、时序监督、误差修正
- **验证方式**：时序预测误差 vs 无前向模型基线；是否提升泛化
- **现有路线**：AwareLiquid-Physic（Hamiltonian + 辛积分）/ World（JEPA）

### 8. 显著性模块（Salience / Value）

- **对应人脑**：杏仁核 + 腹侧纹状体
- **功能目标**：对输入快速打显著性 / 价值标签
- **系统目标**：决定「什么值得注意 / 记忆 / 行动」
- **输入**：感知 / 情景信号
- **输出**：salience / value 标签
- **交叉点（环）**：调制注意、记忆编码、动作选择（RPE 的价值端）
- **归纳偏置**：快速、无监督的价值估计
- **验证方式**：能否正确标注关键 token/事件；消融后注意/记忆是否退化
- **现有路线**：待建

### 9. 内部模拟模块（Internal Simulation / DMN）

- **对应人脑**：默认模式网络 DMN（无外部输入的自发生成、心理时间旅行）
- **功能目标**：无外部输入时自发生成 / 模拟场景，支持规划
- **系统目标**：离线想象、反事实推理、规划
- **输入**：微弱 / 无外部输入（自发）
- **输出**：生成的内部场景 / 轨迹
- **交叉点（环）**：向审慎推理提供候选；回放进记忆固化
- **归纳偏置**：自发生成、反事实模拟
- **验证方式**：规划任务上内部模拟 vs 无模拟的性能对比
- **现有路线**：M2（workspace / 实验机制）

### 10. 审慎推理 / 路由模块（Deliberation Router）

- **对应人脑**：前额叶 System 2（deliberate）+ 基底节动作选择
- **功能目标**：决定「快思考」直出 vs「慢思考」多步推理，并路由
- **系统目标**：计算资源自适应分配
- **输入**：状态置信度、任务难度、显著性信号
- **输出**：路由决策（直出 / 展开推理 / 检索记忆 / 内部模拟）
- **交叉点（环）**：CBGTC 环；调用内部模拟（DMN）、工作 / 情景记忆
- **归纳偏置**：自适应计算
- **验证方式**：简单任务不浪费计算、困难任务触发推理的准确率–计算量曲线
- **现有路线**：deliberation router（M1）

## 4. 机制层说明（横切，贯穿功能系统）

### 连续时间动力学（LTC）

- **作用机制**：ODE `h'(t) = f(h, I, t, θ)` 连续演化状态，时间常数自适应
- **贯穿模块**：所有功能系统的「状态承载」底层
- **归纳偏置**：连续时间演化
- **验证方式**：参数–性能曲线 vs 离散 Transformer
- **现有路线**：LTC substrate（Physic / M1）

### 可塑性规则（STDP / Hebbian）

- **作用机制**：局部、时序因果的权重更新，替代 / 补充反向传播
- **贯穿模块**：各模块的连接权重
- **归纳偏置**：时序因果、局部更新
- **验证方式**：局部规则 vs BP 的精度差；持续学习不遗忘
- **现有路线**：待建

### 神经调质广播（Neuromodulation）

- **作用机制**：少数核团广播低维信号，调制学习率 / 探索利用 / 时间尺度
- **贯穿模块**：全脑广播（环 5）
- **归纳偏置**：全局低维调制
- **验证方式**：调制信号能否切换行为模式（探索 / 利用）
- **现有路线**：待建（human-brain-simulation 可借）

### 预测编码（贯穿原则）

- **作用机制**：每个皮层层级都有「预测单元 + 误差单元」，误差自下而上传播，预测自上而下
- **贯穿模块**：所有皮层模块（环 6）
- **归纳偏置**：逐步修正 / 去噪
- **验证方式**：误差驱动修正 vs 纯自回归基线的泛化对比
- **现有路线**：AwareLiquid-World（JEPA 潜状态预测）

## 5. 环拓扑（连接是环，不是清单）

### 环 1：丘脑–皮层双向环（Thalamo-cortical re-entrant loop）

丘脑 ⇄ 皮层双向。丘脑不是单纯中继，还承担感觉门控与注意调制。
**涉及**：感知编码(1) ⇄ 注意力(5) ⇄ 工作记忆(2)。

### 环 2：皮层–基底节–丘脑–皮层环（CBGTC loop）

皮层 → 纹状体 → 苍白球 → 丘脑 → 回皮层；多巴胺 RPE 调制纹状体可塑性。
**涉及**：动作选择(6) ⇄ 审慎推理(10) ⇄ 注意/门控。

### 环 3：海马–皮层固化对话（Systems consolidation）

海马快速编码情景 → 睡眠 / 回放中向新皮层转移固化。
**涉及**：情景记忆(3) → 记忆固化(4)。

### 环 4：小脑–皮层环（Cerebro-cerebellar loop）

皮层 → 脑桥 → 小脑 → 丘脑 → 回皮层；小脑做前向模型 / 时序误差修正。
**涉及**：前向模型(7) ⇄ 感知编码(1) ⇄ 动作选择(6)。

### 环 5：神经调质广播（Neuromodulatory broadcast）

多巴胺 / 血清素 / 乙酰胆碱 / 去甲肾上腺素，少数核团广播到全脑。
**涉及**：所有模块（尤其调制学习率、探索利用、时间尺度）。

### 环 6：预测编码层级误差传播（Predictive-coding error propagation）

每层预测下一层，误差自下而上、预测自上而下。
**涉及**：贯穿所有皮层模块（机制，非单模块）。

## 7. 依赖关系与排期

**依赖**：
- **M1（连续时间动力学）是地基**，所有组件都挂在它上面。
- T1（感知）→ T2/T3/T5（记忆/注意）是上游；T3→T4 是记忆固化链。
- T7（前向模型）是核心创新，与 M2（预测编码试点）绑定。
- T6/T8（动作选择/显著性）构成 RL 链路，依赖 T2/T3 的价值/记忆。
- T9（内部模拟）→ T10（审慎）是规划层，依赖 T2/T3/T7。

**建议排期**：
1. **核心闭环**：T1 + T2 + T5（感知–记忆–注意）＋ M1 地基
2. **记忆链 + 核心创新**：T3 + T4 + T7（+ M2 试点）
3. **RL + 规划层**：T6 + T8 + T9 + T10
4. **范式探索收尾**：M3（神经调质）+ M4（可塑性规则）
