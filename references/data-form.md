# 数据形态 / 监督层

> **第四维度**，与「机制层 / 功能系统层 / 环拓扑」并列。
> 数据形态直接决定**拟合目标**，而拟合目标是智能跃迁的核心瓶颈（见纪要结论 2）。
> **换架构不同步换数据形态 = 只换了一半范式。**

---

## 1. 核心论点：数据形态 = 拟合目标

- 传统 LLM 数据形态 = 原始文本 → tokenize → 「预测下一个 token」的交叉熵。
  这个数据形态**本身**就是自回归范式：监督信号 = 下一个 token。
- 换了架构（连续时间动力学、归纳偏置），但监督信号仍是「下一个 token」，
  等于从数据入口把自回归瓶颈又请了回来。
- 文本是「离散 + 静态」的：token 顺序 ≠ 物理时间，没有真正的时间 / 事件 / 因果结构。
  连续时间动力学在 next-token 文本上**无处演化**，归纳偏置被浪费。
- 结论：**架构换了一半**。要换全，数据形态 + 监督信号必须同步换。

## 2. 决策规则

**换架构必须同步审视数据形态 / 监督信号。** 评审任何架构改动时追问一句：

> 「这个改动的监督信号变了吗？还是仍然在拟合下一个 token？」

若监督信号没变，则改动至多是量变。

**适合类脑模型的数据形态特征**（对比传统文本）：

| 维度 | 传统 LLM 数据 | 类脑模型应需 |
|---|---|---|
| 信号形式 | 离散 token | 连续 / 时序信号（音频、传感器、事件流、轨迹） |
| 时间结构 | 静态快照 | 事件 / 状态转移（有物理时间与因果） |
| 监督信号 | 预测下一个 token | 预测下一状态 / 去噪 / 前向模型 / RPE |
| 数据结构 | 扁平文本 | episode / 轨迹结构 |

## 3. 组件 → 数据形态 → 监督信号

| 组件（功能系统层） | 需要的数据形态 | 监督信号（替代 next-token） |
|---|---|---|
| 感知编码 | 音频 / 传感器 / 事件流 / 视频 | 多模态重建 / 对齐 |
| 工作记忆 | 长程依赖序列 | 检索 / 召回 |
| 情景记忆 | **episode 结构**（非扁平文本） | 一次性记忆检索 |
| 记忆固化 | 离线回放协议 | 巩固不遗忘 |
| 前向模型（小脑） | **状态转移轨迹** `(s_t, a_t, s_{t+1})` | 预测下一状态 |
| 动作选择（基底节） | **经验轨迹** `(s, a, r, s')` | 奖赏预测误差 RPE |
| 显著性（杏仁核） | 带显著事件的流 | 关键事件标注 |
| 内部模拟（DMN） | 可生成的场景轨迹 | 反事实生成 |
| 审慎推理 / 路由 | 难度分层任务集 | 自适应计算奖励 |

| 机制（机制层） | 数据 / 监督要求 |
|---|---|
| 连续时间动力学 | 需要**时序信号**（非静态文本），否则 ODE 无处演化 |
| 可塑性规则 | 需要在线 / 流式数据，局部时序因果 |
| 神经调质广播 | 需要奖赏 / 价值信号（驱动 RPE 调制） |
| 预测编码 | **加噪 → 去噪对**（corrupted → clean），逐步修正 |

**关键洞察**：扩散模型之所以有效，正是因为它的数据形态是「噪声 → 清晰」对、监督信号是
「逐步去噪」，与它的归纳偏置绑定。要借扩散的收益，就必须同步搭「加噪 → 去噪」的数据形态，
而不是继续喂文本。

## 4. 落地原则（小步验证）

- 别一步到位搞「全新数据体系」——先在**一个模态、一个组件**上验证：
  证明归纳偏置真的被激活、泛化真的提升，再扩展。
- AwareLiquid-World 的 audio / sensor / event-stream / physics 多模态是最好起点
  （方向已对，直接深化）。
- 数据形态改造 = 训练目标改造 = 底层重构（纪要结论 3 的门槛）。
  当「范式探索」立项，不当「换个数据集」的工程活。

## 5. 风险与边界

- **文本不能全丢**：语言能力与常识仍靠文本；目标是「多形态 + 监督信号多样化」，
  不是「去掉文本」。
- **合成 / 世界模型数据**（状态转移轨迹）可作前向模型训练源，但要注意 sim-to-real 泛化 gap。
- **多监督信号并存**时，先明确主监督信号，避免多个目标互相拉扯导致训练失稳。
